Common questions

Do I need to create an account?
No. Enter a display name and either host a new quiz or join one with a code — that's it.

How do I host a quiz?
From the home screen, choose Create quiz, pick your settings and round topics, then share the join code shown in the lobby with the other players.

Why did the game end or reset unexpectedly?
Quiz sessions live only in the server's memory while they're active — a lost connection or a server restart can end an in-progress game. Rejoin with the same code to see if the session is still there.

Someone was using an inappropriate name or topic — what do I do?
Every lobby has a Report button next to each player, and a host can remove a player from their own lobby directly. Reports are reviewed for moderation. If you'd rather email us directly, use the address above.

What data does the app collect?
See the Privacy Policy for the full picture — in short, there's no account and nothing is kept once a quiz session ends, aside from report logs used for moderation.
